# Kết quả lịch sử

`recommendation_ablation.json` lưu kết quả các ranker overlap, weighted Jaccard
và hybrid đã bị loại khỏi runtime. Artifact vẫn được dùng để kể lại quá trình
chọn thiết kế, nhưng repo hiện không cung cấp workflow production để tái tạo nó.

Không trình bày các số liệu này như phương pháp đang được API sử dụng.
