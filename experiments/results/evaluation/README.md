# Kết quả evaluator

Chứa metric entity resolution, QA Neo4j, co-star reasoning và recommendation
production. Nguồn tương ứng nằm trong `experiments/evaluation/`; corpus nằm trong
`experiments/corpora/silver/`.

Các kết quả hiện tại dùng silver/smoke evidence và chỉ có ý nghĩa trong phạm vi
case, rubric và snapshot được ghi trong artifact.
