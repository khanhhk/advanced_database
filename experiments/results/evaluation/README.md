# Kết quả evaluator

Chứa metric entity resolution, QA Neo4j, co-star reasoning và recommendation
production. Nguồn tương ứng nằm trong `experiments/evaluation/`; corpus nằm trong
`experiments/corpora/silver/` hoặc `experiments/corpora/human_review/`.

Các kết quả hiện tại dùng silver/smoke evidence. Chỉ thêm kết quả human-reviewed
khi review metadata vượt qua validator.
