# Kết quả thực nghiệm

Artifact được phân nhóm thành `quality/`, `evaluation/`, `benchmarks/`,
`history/` và `summary/`. Mỗi thư mục con mô tả nguồn sinh và mức
độ sử dụng của file.

Không chỉnh sửa số liệu bằng tay. Khi chạy lại thí nghiệm, giữ cùng snapshot,
cấu hình và guard; sau đó tái tạo summary, hình báo cáo và slide.
