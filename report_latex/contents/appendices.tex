\chapter{Hướng dẫn cài đặt và chạy chương trình}

Môi trường yêu cầu Python 3.11 trở lên, Docker và Docker Compose. Các biến cấu
hình được khai báo trong \texttt{.env}; khóa \texttt{TMDB\_API\_KEY} chỉ cần thiết khi thu thập
lại dữ liệu. Quy trình chạy cơ bản như sau:

\begin{Verbatim}[fontsize=\scriptsize,frame=single]
make setup
make data DATA_COUNT=5000
make demo
\end{Verbatim}

Sau khi khởi động, giao diện web có tại \texttt{http://localhost:8000/} và tài liệu API
Swagger có tại \texttt{http://localhost:8000/docs}. Kiểm tra toàn bộ hệ thống bằng:

\begin{Verbatim}[fontsize=\scriptsize,frame=single]
make test
.venv/bin/python -m experiments.evaluation.audit_knowledge_quality
.venv/bin/python -m experiments.evaluation.evaluate_entity_resolution \
  experiments/corpora/silver/entity_resolution.json \
  --output experiments/results/evaluation/entity_resolution.json
docker compose --profile semantic up -d --build jena
.venv/bin/python -m experiments.semantic.evaluate_jena
docker compose --profile semantic stop jena
docker compose --profile test up -d --wait neo4j-test
RUN_NEO4J_TESTS=1 ALLOW_NEO4J_TEST_RESET=1 \
  ALLOW_MULTISCALE_BENCHMARK=1 NEO4J_URI=bolt://localhost:7688 \
  NEO4J_PASSWORD=test-password \
  .venv/bin/python -m experiments.benchmarks.benchmark_multiscale
\end{Verbatim}

\texttt{make demo} so processed checksum để chỉ import lại khi CSV graph thực sự thay đổi.
Dữ liệu Neo4j kiểm thử chạy ở Bolt 7688 và tách biệt với graph demo. Bốn lệnh đánh
giá phía trên không cần chạy trong buổi demo; chúng tái tạo quality audit, review
pack, Jena/Fuseki result và benchmark đa quy mô.

\chapter{API và ví dụ sử dụng}

\begin{longtable}{|>{\raggedright\arraybackslash}p{0.29\textwidth}|>{\raggedright\arraybackslash}p{0.29\textwidth}|>{\raggedright\arraybackslash}p{0.29\textwidth}|}
\caption{Tổng hợp api và ví dụ sử dụng}\label{tab:app-1} \\
\hline
\textbf{Phương thức} & \textbf{Endpoint} & \textbf{Chức năng} \\ \hline
\endfirsthead\hline \textbf{Phương thức} & \textbf{Endpoint} & \textbf{Chức năng} \\ \hline\endhead
\texttt{GET} & \texttt{/health} & Kiểm tra kết nối Knowledge Graph \\ \hline
\texttt{GET} & \texttt{/stats} & Trả số lượng node và relationship \\ \hline
\texttt{GET} & \texttt{/entities/search?q=...} & Tìm Movie, Person, Genre, Keyword hoặc Studio \\ \hline
\texttt{POST} & \texttt{/ask} & Hỏi–đáp bằng ngôn ngữ tự nhiên \\ \hline
\texttt{POST} & \texttt{/recommend} & Gợi ý phim theo TMDB ID \\ \hline
\end{longtable}

Ví dụ gửi câu hỏi:

\begin{Verbatim}[fontsize=\scriptsize,frame=single]
curl -X POST http://localhost:8000/ask \
  -H 'Content-Type: application/json' \
  -d '{"question":"Những phim nào do Christopher Nolan đạo diễn?"}'
\end{Verbatim}

Response gồm \texttt{answer}, \texttt{intent}, \texttt{evidence} và \texttt{query\_time\_ms}. Ví dụ yêu cầu gợi
ý ba phim tương tự \texttt{Inception}:

\begin{Verbatim}[fontsize=\scriptsize,frame=single]
curl -X POST http://localhost:8000/recommend \
  -H 'Content-Type: application/json' \
  -d '{"movie_id":27205,"top_k":3}'
\end{Verbatim}

Mỗi recommendation trả \texttt{movie\_id}, \texttt{title}, \texttt{score}, các feature chung theo từng
loại và câu giải thích được dựng từ chính các feature đã đóng góp vào điểm.

\chapter{Truy vấn minh họa}

Truy vấn Cypher tìm phim theo đạo diễn:

\begin{Verbatim}[fontsize=\scriptsize,frame=single]
MATCH (p:Person)-[:DIRECTED]->(m:Movie)
WHERE toLower(p.name) = toLower($director)
RETURN m.tmdb_id AS movie_id, m.title AS title
ORDER BY m.release_date
\end{Verbatim}

Truy vấn Cypher sử dụng quan hệ suy diễn để tìm bạn diễn:

\begin{Verbatim}[fontsize=\scriptsize,frame=single]
MATCH (a:Person)-[r:CO_STARRED_WITH]-(b:Person)
WHERE toLower(a.name) = toLower($person)
RETURN b.name, r.movie_count, r.evidence_movie_ids
ORDER BY r.movie_count DESC
\end{Verbatim}

Truy vấn SPARQL sử dụng inverse relation sau semantic materialization:

\begin{Verbatim}[fontsize=\scriptsize,frame=single]
PREFIX : <https://example.org/movie-kg/>
SELECT ?movie ?actor
WHERE { ?movie :hasActor ?actor }
\end{Verbatim}

Catalog đầy đủ gồm 10 truy vấn Cypher tại \texttt{cypher/queries.cypher} và 10 truy vấn
SPARQL tại \texttt{sparql/queries.rq}. Các truy vấn do ứng dụng thực thi được tham số hóa
và quản lý tập trung trong \texttt{src/kg/query\_catalog.py}.
