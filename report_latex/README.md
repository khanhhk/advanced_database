# Báo cáo LaTeX

Thư mục này là bộ nguồn LaTeX tự chứa để tải thủ công lên Overleaf. `main.tex`
lắp ghép các chương trong `contents/`, bibliography trong `ref.bib` và asset hình
trong `images/`.

Chỉnh sửa trực tiếp `main.tex`, `titlepage.tex`, `contents/*.tex` và `ref.bib`.
Trên Overleaf, chọn pdfLaTeX làm compiler và đặt `main.tex` là main document.

Repository không lưu PDF báo cáo cuối và không cung cấp script tự sinh LaTeX hay
biên dịch PDF. Các PDF trong `images/` là asset bắt buộc của báo cáo, không phải
file báo cáo đầu ra.
