# Defense

Tài liệu chuẩn bị trang chiếu, diễn tập và trả lời phản biện:

- [slide-outline.md](slide-outline.md): nội dung và thời lượng dự kiến từng trang chiếu.
- [defense-script.md](defense-script.md): kịch bản trình bày/trình diễn và nhật ký diễn
  tập cần người trình bày tự hoàn thành.
- [defense-qa.md](defense-qa.md): bộ câu hỏi phản biện kèm định hướng trả lời.

Repository không lưu trang chiếu PDF/PPTX. Các tài liệu này là cơ sở để người trình
bày tự hoàn thiện trang chiếu và diễn tập.
