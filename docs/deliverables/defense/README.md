# Defense

Tài liệu chuẩn bị slide, diễn tập và trả lời phản biện:

- [slide-outline.md](slide-outline.md): nội dung và thời lượng dự kiến từng slide.
- [defense-script.md](defense-script.md): kịch bản trình bày/demo và nhật ký diễn
  tập cần người trình bày tự hoàn thành.
- [defense-qa.md](defense-qa.md): bộ câu hỏi phản biện kèm định hướng trả lời.

Repository không lưu slide PDF/PPTX. Các tài liệu này là cơ sở để người trình
bày tự hoàn thiện slide và diễn tập.
