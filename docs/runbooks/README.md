# Runbooks

Các hướng dẫn có thể thực hiện từng bước để chuẩn bị, vận hành và demo hệ thống.

## Nội dung

- [demo.md](demo.md): trình tự chuẩn bị và demo đầy đủ Movie Knowledge Graph.
- [dbeaver-neo4j.md](dbeaver-neo4j.md): cấu hình DBeaver Community để duyệt và
  truy vấn Neo4j.
Tài liệu DBeaver là một nhánh vận hành tùy chọn; demo cơ bản chỉ cần Neo4j,
FastAPI và giao diện web.
